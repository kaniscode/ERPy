# Optional multiscale detector: predeclared comparison

Predeclared before any candidate outcomes; internal analysis plan, not a registered protocol.

The candidate uses the fixed windows10–90,90–300 and10–300ms. Each window retains the existing maximum-p projection–energy conjunction. The contact p-value is min(1,3×minimum window p); unavailable windows contribute1 without reducing3. BH then includes all four declared contacts, with availability retained separately. This detects evidence for at least one window, under the global null that every declared window satisfies at least one of its two component nulls. Cross-window independence is unnecessary for Bonferroni; BH still needs its usual cross-contact conditions. This is an optional candidate, not an automatic default replacement.

The frozen design contains2000 independent four-contact families:1440 signal families across3 trial counts×3 signal levels×4 shapes×2 polarities×20 replicates;240 stationary-noise families;320 globally valid component-null families. The current early10–90ms and broad15–300ms single-window methods are primary references; single late and matched-broad10–300ms results are retained as diagnostics. All methods see identical data and reused window p-values.

At eight trials, an isolated four-contact discovery faces the exact Bonferroni/BH floor12/128=.09375. This anticipated loss is part of the comparison, not a reason to change the candidate after seeing results. Every cell, failure and unavailable outcome will be reported. Null stresses address both component branches across all candidate windows. The energy-null branch uses exchangeable positive ramp slopes so every matched-window energy difference has the required joint symmetry, rather than assuming a full-window construction remains null at shorter scales.

The JSON plan specifies all parameters, generators, seeds, estimands and uncertainty. Optional source-verified CC0 prestimulation fixtures use a frozen label-independent selection rule and are only semi-synthetic characterization. No natural-noise clinical false-positive rate or superiority claim is inferred. The analysis is one bounded candidate evaluation; windows/thresholds will not be tuned to obtain a winner.
