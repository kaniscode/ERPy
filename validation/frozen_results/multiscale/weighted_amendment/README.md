This amendment was written after the unweighted results were observed and before calculating any weighted outcomes. The frozen weights are early 0.1, late 0.1, broad 0.8. Missing windows retain their original weights. This is one final bounded candidate, justified by the anticipated eight-trial resolution failure, not a preregistered first analysis.

Development outcomes will be recombined from preserved window p-values. A fresh 2,000-family run uses the exact prior grid and the fixed namespace `weighted-confirmation-20260908-01`.
